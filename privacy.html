Privacy

RomitCSV is designed so its CSV processing tools can run in your browser. The core viewer, editor, cleaner, merger, splitter, validator and CSV/JSON converters process selected data locally rather than uploading the file to a RomitCSV server.

Files

Your selected CSV or TSV file is processed by the browser. The homepage may temporarily place the selected file in browser IndexedDB so the viewer can open it after navigation. That browser storage is not a server upload.

Browser storage

Theme preferences and the temporary file handoff use browser storage. You can clear site data through your browser settings.

Third-party services

Only make stronger privacy claims after checking the scripts and analytics used on the deployed site.

Changes

This page may be updated when the site's data handling changes.
